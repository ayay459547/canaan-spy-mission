# canaan-spy-mission

建立一個沉浸式 解謎活動介紹網站。

主題：
「曠野中的十二探子」

風格：
聖經冒險 + 曠野探索 + 解謎 + 兒童營會風格。

目標族群：
國小學生、教會兒童營、主日學活動。

網站風格：

- 冒險感
- 神秘感
- 曠野探索
- 古代以色列風格
- 有地圖、卷軸、火把、巨人腳印等元素
- 動畫感強
- 適合兒童閱讀
- 色調使用：
  沙漠金色、深棕色、羊皮紙色、橘黃色火光、深藍夜空

整體 UI：

- Hero Section 大型標題
- RPG 任務風格
- 卡牌式關卡介紹
- 有探險地圖感
- 有捲軸樣式區塊
- 滑動時有動畫
- 響應式設計
- 適合手機瀏覽

首頁 Hero 區塊：
大標題：
「曠野中的十二探子」

副標題：
「你願意成為探子，探索神所應許的迦南地嗎？」

加入：

- 探子剪影
- 曠野背景
- 遠方巨大城牆
- 巨人腳印
- 火把與星空

按鈕：
「開始冒險」
「加入探子行列」

加入浮動動畫：

- 沙塵
- 火光
- 星星
- 地圖光點

第二區：
故事背景

內容：
摩西派出十二探子進入迦南地。
他們看見豐盛的土地、高大的城牆，以及可怕的巨人。
有人選擇害怕，
有人選擇相信神。

核心主題：
「真正的勇敢，不是沒有害怕，而是害怕時仍願意相信神。」

第三區：
活動特色（使用卡片 Grid）

卡片內容：

1. RPG 劇情探索
2. 多人合作解謎
3. 巨人與城牆挑戰
4. 信心石收集系統
5. 投票選擇劇情
6. 最終勇士身份揭曉

每張卡片有：

- Icon
- Hover 動畫
- 微發光效果

第四區：
五大關卡介紹（時間軸設計）

關卡順序：

1.

「進入迦南地」
尋找失落地圖碎片，
找到應許之地入口。

2.

「流奶與蜜之地」
探索豐盛的迦南地，
找到神應許的祝福。

3.

「高大城牆」
破解迦南城門密碼，
尋找進城方法。

4.

「亞衲族巨人」
在黑暗中探索，
找到隱藏的「不要害怕」。

5.

「葡萄谷搬運」
團隊合作搬運巨大葡萄串。

每個關卡：

- 有插圖
- 有動畫
- 有任務標籤
- 有難度星級
- 有 RPG 任務感

第五區：
信心石系統

使用發光藍色寶石視覺。

內容：
玩家在活動中，
透過：

- 勇敢
- 合作
- 鼓勵朋友
- 不放棄

收集「信心石」。

最後會根據數量獲得不同稱號：

- 曠野旅人
- 勇敢探子
- 約書亞／迦勒勇士

加入寶石收集動畫。

第六區：
最終投票

畫面呈現：
大量探子聚集。

內容：
「我們要進入迦南地嗎？」

加入：

- 藍色投票牌
- 群眾壓力感
- 緊張氣氛
- 火把動畫

第七區：
活動資訊

使用漂亮資訊卡。

內容：

- 活動時間：約 60 分鐘
- 適合年齡：國小學生
- 活動形式：RPG + 解謎 + 團隊合作
- 適合：主日學、兒童營、教會活動

第八區：
最後 Message 區塊

大字：
「十二探子看見的是同樣的巨人，
但約書亞與迦勒選擇相信神。」

小字：
「真正的勇敢，
不是沒有害怕，
而是害怕時仍願意相信神。」

背景：
星空＋應許之地光芒。

頁尾：
加入：

- 羊皮紙風格 Footer
- 十字架小圖示
- 探子腳印元素

技術需求：

- 使用 React
- 使用 Tailwind CSS
- 動畫使用 Framer Motion
- UI 乾淨高級
- 有 RPG 遊戲感
- 有兒童冒險風格
- 支援深色模式
- 視差滾動效果
- 關卡卡片 hover 特效
- Hero section 全螢幕

整體感覺：
像「聖經版 RPG 冒險活動網站」。
